# 组会论文汇报 PPT 制作 Skill

本文件夹包含一个完整的组会 PPT 制作指南和配套 Python 模板，从 3 份已验收的 deck（66–73 页）和反复迭代中提炼而来。

## 文件说明

| 文件 | 用途 |
|------|------|
| `SKILL.md` | **核心规范文档**：配色、字体、页面骨架、备注写法、流程图重绘、常见错误清单 |
| `ppt_template.py` | **Python 模板脚本**：用 python-pptx 实现所有页面类型，可直接调用生成 PPT |
| `demo_output.pptx` | 模板脚本生成的 17 页演示样例 |
| `README.md` | 本文件 |
| `模板.pptx` | **空白模板**，16 页预置骨架，可手动在 PowerPoint 中编辑 |

## 快速开始

### 1. 安装依赖

```bash
pip install python-pptx
```

### 2. 运行演示

```bash
cd ppt-making-skill
python ppt_template.py
```

会生成 `demo_output.pptx`（17 页），包含封面、章节分隔、内容、文献综述、模块导览、子节内容、公式、对比表格、串联对比、结尾等所有页面类型。

### 3. 制作新 PPT

复制 `ppt_template.py`，修改 `demo()` 函数里的内容：

```python
from ppt_template import *

prs = create_presentation()

# 封面
add_cover_page(prs, "论文中文标题", "English Title", "安徽理工大学", "汇报人", "2026-10-30")

# 问题背景页（带渐变标签按钮）
add_background_page(prs, "研究动机文本", "创新点列表", "备注")

# 章节分隔
add_section_divider(prs, 1, "引言")

# 内容页
add_content_page(prs, "标题", "正文内容", "备注文字")

# 相关工作分类综述
add_related_work_page(prs, "类别名", [
    {"ref_number":1, "title":"文献标题", "content":"摘要"},
    {"ref_number":2, "title":"文献标题", "content":"摘要"},
], notes_text="备注")

# 相关工作总结表格
add_related_work_summary(prs, "相关工作总结", [
    {"name":"类别一", "refs":"[1][2][3]", "strength":"优点", "weakness":"不足"},
], conclusion="本文怎么补齐缺口", notes_text="备注")

# 模块导览页
add_module_overview_page(prs, "模块 ①", "神经网络给出概率",
    ["1.1 学会下一步", "1.2 网络结构"], notes_text="备注")

# 子节内容页
add_subsection_page(prs, "1.1", "从历史前缀学会概率", "正文", notes_text="备注")

# 公式页
add_formula_page(prs, "融合公式", ["π' ∝ π^w × C^(1-w)"],
    symbol_table=[("π", "神经网络概率"), ("C", "合规度")], notes_text="备注")

# 对比表格
add_comparison_table(prs, "对比标题", ["维度","A","B"], [["key","v1","v2"]], "备注")

# 图片内容页
add_image_content_page(prs, "框架图", "framework.png", "底部说明", notes_text="备注")

# 串联对比页
add_paper_comparison_page(prs, "对比",
    {"name":"论文A","features":["特征1"]}, {"name":"论文B","features":["特征2"]})

# 结尾
add_ending_page(prs)

prs.save("output.pptx")
```

## 核心规范速查

### 配色

- 主色：深蓝 `#122E66`、红色 `#FF0000`、橙色 `#E67E22`
- 正文：深灰 `#333333`
- 背景：白 `#FFFFFF`、浅蓝 `#EEF2F8`、浅橙 `#FDF0E3`、浅绿 `#E8F5E9`

### 字体

- 中文正文：Noto Sans SC 16–18pt
- 中文标题：微软雅黑 22–32pt 加粗
- 英文：Arial / Times New Roman
- 章节大数字：Impact 166pt

### 页面结构

```
封面(1) → 背景(1) → ◆01引言(1+2) → ◆02相关工作(1+3~6) → 
◆03方法(1+21~42) → ◆04实验(1+3~8) → ◆05结论(1+1) → 结尾(1)
```

方法章节四阶段：**基础知识(3~6页) → 方法框架(2~3页) → 详细讲解(15~30页) → 方法总结(1~2页)**

### 备注规范

- 每页 150–450 字
- **角色代入**：你是汇报的学生，在讲台上给老师和同学讲，像说话不像写论文
- **三段式**：目的（这页讲什么）→ 讲解（原理+例子+数字）→ 衔接（下一页讲什么）
- 双语域：学术术语（英文原文）+ 口语化白话解释
- 不复述页面文字，写因果和例子

### 流程图

- 方法流程图：**必须重绘成中文版**
- 结果图表：保留论文原图
- 总览框架图：只画一次，后续用红框标出当前位置

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 贴英文原图 | 重绘中文流程图 |
| 备注复述页面 | 写因果+例子 |
| 备注超500字 | 拆页 |
| 方框塞多行 | 每格一行 |
| 总览图重复贴 | 只画一次+红框回指 |
| 字体混用 | 统一Noto Sans SC+微软雅黑 |
