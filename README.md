# 组会论文汇报 PPT Skill

本目录为中文论文组会汇报提供个人风格指南、参考模板和可选的 Python 页面生成脚本。写作与核验流程见 [SKILL.md](SKILL.md)。

## 目录文件

- `SKILL.md`：论文证据核对、汇报结构、示意案例、备注和交付检查。
- `模板.pptx`：16 页参考模板，保留了旧论文的标题、内容和备注，使用副本时必须逐页清理。第 10、12 页均显示章节编号 04，须按新汇报调整。
- `ppt_template.py`：使用 `python-pptx` 生成近似该模板风格的页面，不保证完整复刻模板的母版、字体、装饰或版式。

## 辅助脚本

依赖 `python-pptx`。在本目录执行 `python ppt_template.py`，会在当前工作目录生成 `demo_output.pptx`，该示例是演示而非经过论文和视觉验收的汇报，不应直接用于组会。默认仓库不包含这个生成文件。命令会覆盖当前目录同名文件，执行前先确认。

```python
from ppt_template import create_presentation, add_content_page

# 新建空白演示文稿，后续页面使用脚本提供的近似装饰
prs = create_presentation()
add_content_page(prs, "研究问题", "填写根据论文核对后的内容", "填写讲稿")
prs.save("output.pptx")
```

如需读取现有模板，显式调用 `create_presentation("模板.pptx")`。这会保留模板中的所有原页面、标题与备注，不会自动清理；其后调用 `add_*_page` 会追加页面，不会替换原页面。应使用支持完整页面复制及关系管理的工具编辑模板，并检查备注及隐藏内容。脚本的 `clone_slide` 不用于复制包含图片、图表、超链接或 OLE 对象的页面。

脚本插图按比例放入目标区域，但不自动验证文字溢出、图表可读性或内容正确性。最终 PPT 必须逐页渲染检查；无法完成的检查要如实说明。

## 来源与适用范围

本指南最初参考了三份现有组会汇报：《基于时间图神经网络与多任务学习的对象中心预测性流程监控》（69 页）、《神经符号预测过程监控》（66 页）、《基于概率声明式知识的神经符号预测过程监控》（73 页）。页数与某篇论文的模块结构是历史样例，不是新汇报的固定要求。新任务以实际论文、听众、时长和用户指定模板为准。
